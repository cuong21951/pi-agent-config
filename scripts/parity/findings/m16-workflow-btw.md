## 4. /btw

Command @ 254680899: `{type:"local-jsx", name:"btw", description:"Ask a quick side question without interrupting the main conversation", immediate:true, keepsScrollPosition:true, argumentHint:"[question]"}`. Handler `ir` and panel `we` in chunk @ 290399523..290430786. Help card hint `/btw for side question` (@ 281097636); tip `Use /btw to ask a quick side question without interrupting Claude's current work`.

What it does: a side question answered by a separate fork-style model call (`Axt({question, cacheSafeParams})` with the main conversation messages as cache-safe context; `forkOrigin:"btw"`, query source `side_question`). It can NOT run tools: if the answer wrote tool calls as text, the transcript text is replaced with `(That answer wrote tool calls as text. Nothing was executed, so it is omitted here.)` and answers carry `_/btw can't run tools: any tool calls or tool output shown above were not executed and may not reflect your actual files or data. Ask in the main conversation to check._` (@ 271737245). It does NOT enter the main conversation: the panel is closed with `onDone(undefined, {display:"skip"})` (no transcript row); exchanges are kept in the in-memory `session.btwHistory` (not sent to the model next turn). Only the `f` key forks it into a real conversation.

Argument rules: `/btw` with no argument and no history prints `Usage: /btw <your question>` (system line). With no argument and history, reopens the last exchange (or the in-flight one) in the panel. `btwUseCount` is incremented in global config. Interactive; in non-interactive sessions runs unwatched and times out after 11 minutes.

Panel look (`we`): column, `paddingLeft:2`, `marginTop:1`, auto-focused (`tabIndex 0`). Top to bottom:
- `(+N earlier /btw)` dim, when more than 5 earlier exchanges exist (`Le=5` shown).
- earlier exchanges: `/btw <question>` one line each, dim (the browsed one bold).
- current: `/btw ` in colour `warning` + bold (dim when browsing history), then the question dim, whitespace-collapsed, truncated to `columns-7` (min 20).
- blank line, then answer area (`marginTop 1`, `marginLeft 2`, `maxHeight = max(5, rows-5-6-historyLines)`), scrollable, `stickyScroll:false`. Content while waiting: spinner glyph + `Answering…` in `warning` (frame counter every 80 ms; with API retry: spinner + `Rate limited`/`API overloaded`/`Authentication failed`/`API error` (warning) + dim ` · retrying in Ns · attempt A/M`). When answered: Markdown render of the response (`sl`), preceded when a refusal fallback happened by a warning-bold notice `<warning glyph> <notice>` with marginBottom 1. Error: error renderer with the message (`No response received`, `Failed to get response`, ...).
- blank line, then dim hint line (Byline ` · `): `shift+left/shift+right`-style `⇧←/⇧→ to browse` when history exists else `↑/↓ to scroll` (when content), `c to copy` (replaced by green `Copied to clipboard` for 2 s), `f to fork` (only when answer exists, not synthetic, not viewing history), `x to clear history` (when history), `esc to close`. While forking: `Forking…`.
Keys: `esc`, `return`, `space`, `ctrl+c`, `ctrl+d` close (no transcript row); `[`/`]` or `shift+left/right` or tab/shift+tab browse older/newer exchanges; up/down or ctrl+p/ctrl+n scroll by 3 lines; `x` clears history; `c` copies the displayed answer (OSC52/clipboard); `f` forks into a new agent (`Cannot fork before the first conversation turn`, success `<EO> forked <name> (<id4>)`; non-interactive branch uses title `btw: <question>`). Stepping aside: if the user starts typing in the main prompt the panel hides and the answer is re-offered later via a `/btw` queued task-notification (priority later).
Fullscreen fix 2.1.304: `/btw` no longer jumps transcript to bottom (`keepsScrollPosition`).

Confidence: command, semantics, keys, text HIGH (read from code); exact colours of the bordered/dim look MEDIUM; anything about how it composes with the prompt (is the prompt hidden while the panel is up?) **needs capture** (the panel is a local-jsx replacing the prompt area like other dialogs; assumed, not observed).
