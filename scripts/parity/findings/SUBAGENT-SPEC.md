# Subagent contract: Claude Code 2.1.283 vs pi (M6-G, 2026-09-29)

Measure + spec only. Nothing in `extensions/`, `patches/` or `npm/` was edited. The UI of the agent rows, list and footer belongs to M6-F; this file covers what the model sees and what the runtime does.

## How it was measured

- Claude: `claude-2.1.283.exe` against `mock.py`, no live model. Synthetic pi sessions (`findings/m6g/gen.py` makes `fg/bg/types/stop/clear.jsonl`) script the main model's replies, and a second turn in the same session, keyed on the subagent's prompt text (`M6G-SUB-…`), scripts the subagent's replies. The mock gets both requests, so `--dump-requests` saves the main loop and the subagent loop.
- `findings/m6g/run_probe.py` runs `run.py` with `findings/m6g/mock_probe.py`, which is `mock.py` plus one change: a `SendMessage`/`TaskStop` argument `"@FIRST"` is replaced with the first `agentId:` Claude handed back, because agent ids are random. `mock.py` and `run.py` were not edited.
- Scenarios: `scenarios/m6g-dump-fg.json`, `m6g-dump-bg.json`, `m6g-dump-types.json`, `m6g-dump-nofork.json` (sets `CLAUDE_CODE_FORK_SUBAGENT=false`), `m6g-dump-stop.json`, `m6g-probe-clear.json`, all run with `--only claude --session findings/m6g/<name>.jsonl --dump-requests`, ports 20650-20657. Raw dumps are in `%TEMP%\pi-parity\m6g-{fg,bg,types,nofork,stop,stop2,stop3,clear}\request-<n>.json`. The committed extracts are in `findings/m6g/claude/`:
  - `main-agent-tools.json`: the full description and schema of Agent, SendMessage, ListAgents, TaskStop, TaskGet, TaskList and Workflow, as sent to the main model
  - `agent-tool-nofork.json`: the Agent tool when the fork gate is off
  - `agent-types-reminder.txt`: the agent-type list
  - `subagent-system*.txt`: subagent system prompts (general-purpose, Explore, Plan, custom)
  - `subagent-request-shape.json`
  - `results.txt`: every tool result and notification quoted below, verbatim
- Bundle: `PARITY_CLAUDE=… py -3.12 findings/m6g/bgrep.py "<needle>" [before] [after] [n]`. `@N` is the byte offset in `claude-2.1.283.exe`.
- pi: `npm/node_modules/@tintinweb/pi-subagents/src/*.ts` (pi loads `src/index.ts` directly, per package.json `"pi.extensions"`; `dist/` is stale and never runs). `patches/pi-subagents.patch` is applied to `src/index.ts` and `src/ui/fleet-list.ts`, and every one of its hunks is rendering only. `subagents.json`, `agents/*.md` (sandbox) and `C:\Users\cuong\.pi\agent\agents\*.md` (real dir, read only) were also read. pi's rows are read from source with `file:line`. This pass has no pi request dump, because pi cannot talk to the mock yet: step 0 of the plan fixes that.

Verdicts: **matches**, **differs → change** (what pi must do), **pi cannot** (why).
